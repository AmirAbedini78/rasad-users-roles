# شرح استفاده از ابزارهای AI

در انجام این تسک از AI به‌عنوان ابزار کمکی در تحلیل، ویرایش کد، آماده‌سازی Docker، عیب‌یابی و مستندسازی استفاده شد. استفاده از AI پنهان نشده و این سند برای شفافیت روند کار ارائه شده است.

## مواردی که AI در آن کمک کرده است

- مرور شرح کار و تبدیل آن به checklist اجرایی
- پیشنهاد و ویرایش بخشی از فایل‌های backend و frontend
- آماده‌سازی Dockerfile و Docker Compose
- کمک به عیب‌یابی مسیر SQLite در Docker
- کمک به ایزوله‌سازی دیتابیس PHPUnit از دیتابیس development
- آماده‌سازی مستندات و roadmap بررسی پروژه

## مواردی که به‌صورت انسانی انجام و تایید شده است

- فهم و بررسی requirementهای پروژه
- اجرای Docker روی سیستم توسعه‌دهنده
- اجرای curl و بررسی status code و JSON
- اجرای feature tests و full test suite
- بررسی تعداد رکوردهای دیتابیس قبل و بعد از تست
- تست دستی frontend، Pinia cache، loading و 401
- بررسی نهایی فایل‌ها قبل از تحویل

## میزان استفاده

درصد دقیق و قابل اتکایی برای سهم AI در یک فرایند توسعه قابل اندازه‌گیری نیست. توصیف دقیق‌تر این است که AI نقش **ابزار کمکی در پیاده‌سازی و مستندسازی** داشته، در حالی که اجرای پروژه، تست‌ها، مشاهده خروجی‌ها و تایید نهایی توسط توسعه‌دهنده انجام شده است.

AI به‌صورت مستقل به محیط کارفرما یا Git دسترسی نداشته و هیچ نتیجه تستی بدون اجرای واقعی به‌عنوان PASS ثبت نشده است.
